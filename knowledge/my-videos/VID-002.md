### BÖLÜM 1: AI AGENT NEDİR? (1:30 - 4:00)
*Tahmini zaman: 2.5 dakika*

Birinci bölümde agent mimarisini anlıyoruz. Kodu yazmadan önce ne kurduğunu bilmek önemli.

**Normal Python kodu ile agent arasındaki fark nedir?**

Normal kodda sen adımları belirlersin. "Önce veriyi yükle, sonra filtrele, sonra ortalamasını al" — her adımı sen yazarsın.

Agent'ta bu farklı. Sen hedefe göre araçlar tanımlarsın, karar mekanizmasını LLM'ye bırakırsın. Agent hedefi alır, hangi araçları kullanacağına kendi karar verir, sonucu inceler, gerekirse tekrar dener.

**Bir agent üç şeyden oluşur.**

Birinci: LLM backbone — GPT-4o, Claude, Gemini. Bu agent'ın beyni.

İkinci: Araçlar — Python fonksiyonları, API'ler, veritabanı sorguları. Bu agent'ın elleri.

Üçüncü: Bellek — kısa süreli konuşma geçmişi veya uzun süreli vector store. Bu agent'ın hafızası.

**Veri analizinde neden işe yarıyor?**

Şöyle düşün: Bir analist her gün aynı tür soruları cevaplamak zorunda. "Bu çeyrekte satışlar nasıl gitti?" "Hangi ürün kategorisi düştü?" "Kasım neden anormal?"

Bu soruların cevabını bulmak SQL, Python, görselleştirme gerektiriyor. Agent bu adımları otomatik yapıyor — sen sadece Türkçe soruyor, cevabı alıyorsun.

**LangChain nereye giriyor?**

LangChain bu üç katmanı — LLM, araçlar, bellek — bir araya getiren framework. 2026 itibarıyla v0.3'e geldi, LangGraph ile stateful yani durumu hatırlayan ajanlar artık standart. 90 binden fazla GitHub star, 200'den fazla LLM entegrasyonu. Türkçe kaynak az ama İngilizce dokümantasyon çok güçlü.

### BÖLÜM 3: PANDAS CSV AGENT (6:00 - 10:00)
*Tahmini zaman: 4 dakika*

Üçüncü bölümde asıl ajan geliyor — CSV dosyasına soru soracağız.

**Dataset hazırla:**

Eğitim amaçlı basit bir satış verisi kullan. Ben bu örnekte şunu yapıyorum:

```python
import pandas as pd

# Örnek dataset — kendin de CSV yükleyebilirsin
data = {
    "ay": ["Ocak", "Şubat", "Mart", "Nisan", "Mayıs", "Haziran"],
    "satis": [12500, 9800, 15200, 11000, 18700, 14300],
    "urun": ["Laptop", "Telefon", "Laptop", "Tablet", "Laptop", "Telefon"],
    "bolge": ["İstanbul", "Ankara", "İzmir", "İstanbul", "Ankara", "İzmir"]
}
df = pd.DataFrame(data)
```

Ya da gerçek bir CSV dosyan varsa:
```python
df = pd.read_csv("satis_verisi.csv")
```

**Agent'ı kur:**

```python
from langchain_experimental.agents import create_pandas_dataframe_agent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

agent = create_pandas_dataframe_agent(
    llm,
    df,
    verbose=True,
    allow_dangerous_code=True,
    agent_executor_kwargs={"handle_parsing_errors": True}
)
```

`verbose=True` açık olsun — agent'ın ne düşündüğünü terminalde göreceksin. Öğrenme için çok değerli.

`allow_dangerous_code=True` — agent Python kodu çalıştırdığı için bu gerekli. Production'da dikkatli kullan.

**İlk soruyu sor:**

```python
sonuc = agent.invoke({"input": "En yüksek satış hangi ayda gerçekleşti?"})
print(sonuc["output"])
```

Terminalde şunu göreceksin: agent önce hangi kodu çalıştıracağına karar veriyor, sonra çalıştırıyor, sonra yorumluyor. Bu döngü agent mantığının özü.

**Daha karmaşık soru:**

```python
sonuc = agent.invoke({
    "input": "Bölgelere göre toplam satışı karşılaştır ve en başarılı bölgeyi söyle."
})
print(sonuc["output"])
```

Agent bu soruyu çözmek için birden fazla adım atacak — groupby, sum, karşılaştırma. Hepsini otomatik yapıyor.

**Bir uyarı:** Agent deterministik değil. Aynı soruya her seferinde aynı kodu yazmayabilir. `temperature=0` bunu azaltır ama sıfırlamaz. Production'da bunu hesaba kat.

### BÖLÜM 4: SINIRLAR VE SONRAKİ ADIM (10:00 - 11:30)
*Tahmini zaman: 1.5 dakika*

Dördüncü bölümde dürüst bir değerlendirme yapalım — agent her şeyi çözmez.

**Ne zaman iyi çalışıyor?**

Tekrar eden analiz soruları için iyi. "Geçen haftanın raporu", "Bu kategorinin trendi", "Anomali var mı?" — bunlar için güçlü.

Çıktıyı doğrulayabildiğin durumlarda güvenli. Agent bir sayı söylüyorsa sen de aynı soruyu SQL ile kontrol edebiliyorsan, kullan.

**Ne zaman dikkatli olunmalı?**

Kritik finansal kararlar için tek başına güvenme. Agent hata yapabilir, halüsinasyon üretebilir. Çıktıyı mutlaka doğrula.

Çok büyük datasetlerde yavaşlıyor ve tokenları tüketiyor — 10 milyon satırlık veri için bu mimari değil.

**Sonraki adımlar neler?**

Bu temel yapı üzerine araçlar ekleyebilirsin — web search, veritabanı bağlantısı, e-posta gönderme. LangGraph ile birden fazla agent'ın birlikte çalıştığı sistemler kurabilirsin. Bunları ilerleyen videolarda inceleyeceğiz.
